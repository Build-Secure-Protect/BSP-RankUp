BSP CORE (required)

Totem events: steals that succeed count as stolen for the thief and lost for the owner, steals that fail while you are online as protected, totems placed. The bank, the coins and (1.3.0) the kits for rewards. The same admin list as every BSP mod. Season ends drive the seasonal rungs.

BSP REGION GUARD (optional)

Buying a plot at the Land Office counts a claim bought. Region Guard's regions and mines are gated by LuckPerms groups: the ranks RankUp hands out open them. The server id is shared.

LUCKPERMS and BSP TELEPORT

LuckPerms holds the ranks (Bukkit plugin on Mohist or the Forge mod): RankUp promotes along a track and sets prefix titles, and can create the track from its ladder. BSP Teleport needs no link; a teams mod can register the team hook so kills between teammates count for nothing.
