MYSQL

bsp_ru_counts, bsp_ru_players, bsp_ru_settings, bsp_ru_images, bsp_ru_notices: one set of tables for the whole network, so playtime on every server adds up, the ladders are the same everywhere, and a prefix image picked on one server shows on all.

REDIS

Settings changes, prefix images and announcements reach every server at once; the notice table carries them when Redis is down.

LUCKPERMS

Its own shared database: a group given on one server holds on all of them, and Region Guard's rank-gated regions see it too.
