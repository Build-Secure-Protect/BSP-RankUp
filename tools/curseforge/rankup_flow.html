WHAT PLAYERS DO

Minutes online, players defeated, mobs killed, Shatter Totems stolen and defended, claims bought... Every one is a signal, on or off, worth so many points per unit.

→

POINTS

Each signal's count times its worth, plus any bonus an admin gave. Lifetime points for permanent rungs; points since the last season end for seasonal ones.

→

THE LADDER

A LuckPerms track: each rung a group, a display name, the points it needs, a seasonal flag and what it gives. Pass a rung's points and you are moved onto its group.

→

RANK UP

LuckPerms gets the group; you get the rewards (coins, pieces, items, a title, commands), a message, and the server hears it. Never downward by points alone.

All of it set in game by an admin; the server config holds only the database connection for a network.
