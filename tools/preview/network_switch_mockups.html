Telling other servers about rank changes: three options

A new switch on OPTIONS (D129): after RankUp changes a player in LuckPerms, it tells the proxy and the other servers through LuckPerms' messaging service, so the network tab list and /players show the new rank within about a second instead of at the next login. It is one shared setting for every server, on by default. The three options differ only in where the switch sits. All three also add a line to the info box saying whether LuckPerms has a messaging service, because without one the push reaches nobody.

A. Beside ANNOUNCE RANK-UPS top row

How it works. The empty right half of the top row gets TELL OTHER SERVERS with on / off chips, like the other switches. Nothing else on the tab moves.

Trade-off. The smallest change, and it sits next to the other "what the network hears" setting. The label is short, so what it does is only in the info line and the docs.

B. A line of its own under the switches

How it works. A new line under the second row: TELL OTHER SERVERS ABOUT RANK CHANGES, on / off, and a short hint after it saying what it does. MAKE TRACK, EXPORT / IMPORT and the info box move down 22 units (there is room above the bottom line).

Trade-off. Says what it does on the screen itself. The tab's lower half moves, so it looks slightly different from 0.5.0.

C. With the LuckPerms button one toggle chip

How it works. On the MAKE TRACK IN LUCKPERMS row, the hint text gives way to one toggle chip, TELL OTHER SERVERS: ON (a click switches it to OFF, red). Everything that talks to LuckPerms sits on one row.

Trade-off. Groups the LuckPerms things together, but a single toggle chip works differently from the on / off pairs everywhere else on the tab, and the MAKE TRACK hint is lost.

Decisions

  1. Which option. Default: A, beside ANNOUNCE RANK-UPS: nothing else moves and it matches the other switches.
  2. The label. Default: "TELL OTHER SERVERS" (A and C) or "TELL OTHER SERVERS ABOUT RANK CHANGES" (B). Another wording is fine, such as "PUSH TO NETWORK".
  3. The info line. Default: yes: "LuckPerms messaging: redis (rank changes reach other servers at once)", or "LuckPerms messaging: none (other servers see rank changes at a player's next login)". With the switch off: "LuckPerms messaging: redis, but TELL OTHER SERVERS is off".

The switch is on by default everywhere (D129); a server with no proxy and no messaging service loses nothing either way.
