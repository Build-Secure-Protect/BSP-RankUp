Prefix images: three options

Decisions D55 to D64. RankUp draws each player's LuckPerms prefix before their name in chat and the tab list. When the prefix's rank has an image, the image is drawn instead of the text. Each option below is the admin screen at its real size (520 by 300 GUI units, drawn at 1.6 pixels a unit). The same example data is used in all three:

Ladder Playtime: the rung Warden gives the title &b[Warden] and Legend gives &6[Legend]. Ladder Raider: Reaver gives &c[Reaver]. Award apple_picker gives &a[Apple Picker].

LuckPerms groups with their own prefix: admin &c[Admin], moderator &9[Mod], founder &6[Founder].

In game the same in every option

Chat and the tab list. Warden, Admin and Mod have images. Apple Picker has none, so its text shows. The text after the name is the player's chat as usual.

A. PREFIXES tab every prefix in one list

How it works. A new PREFIXES tab between PLAYERS and OPTIONS. The left side lists every prefix, grouped by where it comes from: each ladder's titles, award titles and LuckPerms groups. Each row shows the image or the text. On the right is the chosen rank: its prefix text, its image at line size and twice that, a chat line preview, and the folder's files to pick from. REFRESH rescans the folder.

Trade-off. Everything about prefixes is in one place, matching your brief: see the prefixes, then assign an image. A seventh tab makes the tab row longer, and you edit a title's text on LADDER or GROUPS but its image here.

B. Image slot on each rank no new tab

How it works. Wherever a TITLE reward shows (a rung on LADDER, an award on GROUPS), the row gains an image slot beside the text. A LuckPerms group's own prefix gets the same slot on GROUPS. Clicking the slot opens a small picker over the editor, with the folder's files.

Trade-off. The image sits next to the text it replaces, with nothing new to learn. But there's no single place that shows every prefix at once: to check which ranks still lack an image you'd go through each ladder and group.

C. Image gallery start from the files

How it works. A PREFIXES tab that shows the folder as a gallery of cards: each image at twice its size, its file name and dimensions, and the ranks using it. Pick an image, then tick the ranks it should replace in the list on the right. Files that are too big show the reason and can't be picked.

Trade-off. Best when one image serves several ranks, or when you drop in a batch of new files. Ranks without an image are harder to spot: they're only in the narrow list on the right, and the prefix text is small there.

Pick one, and the open questions

Each question has a default in gold; say only where you want something else.

  1. Layout: A, B or C, or parts combined. Default: A, with B's small image slot also shown (read-only, with a jump to PREFIXES) beside TITLE rewards on LADDER and GROUPS.
  2. Which prefix a player shows: the one LuckPerms ranks highest, as LuckPerms decides from priorities. RankUp titles are at 1000 and below, so a group prefix above 1000 (such as Admin) beats them. Default: yes, exactly what LuckPerms shows.
  3. Chat format: vanilla's <name> message with the prefix inside the brackets before the name, and the prefix text keeping its & colour codes. Default: yes.
  4. A space after the image: one pixel of space after the image, then the name. Default: yes.
  5. Group prefixes are read-only in RankUp: PREFIXES shows a group's prefix from LuckPerms; you change the text in LuckPerms. RankUp titles keep being edited on LADDER and GROUPS. Default: yes.
  6. One image on several ranks: allowed. Default: yes.
  7. Deleting a file from the folder after assigning it changes nothing, since the image is saved in the shared storage. The list marks it "not in folder" so you know. Default: yes.
  8. Hovering an image in chat shows the prefix text and the rank's name. Default: yes.
  9. Console and logs show the prefix text, never the image's stand-in character. Default: yes.
  10. Updating: new packets (protocol 3), so the server and the players' modpack update together. Default: accepted.
