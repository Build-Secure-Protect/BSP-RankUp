Decisions

  1. 1. Which VIP

    Default: A, the gilded banner. It matches every other tag in shape, and the purple and gold make it the fanciest-looking of the banners. Any VIP can go with any BUG.

  2. 2. Which BUG

    Default: A, the beetle on a disc. It sits after the name with the achievement icons, as a badge. C is the one to pick if you want it before the name as a tag.

  3. 3. Where they sit

    Default: VIP is a prefix, after the staff tag and before the ladder rank ([Admin] [VIP] [Legend] name); BUG (A or B) is a suffix after the name, last after the achievements. That order is set in LuckPerms' prefix and suffix stacks (BSP-Luckperms/bsp-ranks), so it goes there as a request.

  4. 4. The LuckPerms groups

    Default: vip and bug_hunter, both outside the ladder (given by hand or by the store), each with a prefix or suffix text for anyone without the images: "[VIP] " and " ✦ Bug Hunter".

  5. 5. Hover notes

    Default: VIP "Supports the BSP server"; BUG "Paid to help fix a bug". Shown when someone hovers the tag in chat.
