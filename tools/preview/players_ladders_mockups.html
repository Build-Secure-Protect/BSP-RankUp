RankUp PLAYERS Tab

PL-1: today PLAYERS shows only the first ladder: its rank in the list, its rank line and points, and SET RANK on its rungs. These are three ways to show a player on every ladder, with the awards they've reached.

Each screen is the admin screen at twice its GUI size. RANKUP is your ladder with its new art. PVP and the three awards are example data, there to show more than one ladder. Mrgregles is selected.

Option A

Ladder chips

Like the LADDER tab: chips over the player pick a ladder. The list's rank and points, the rank line, the bright counts and SET RANK all follow that ladder. The AWARDS chip swaps the pane for each award's progress.

For Smallest change; the same habit as LADDER; room for many ladders.

Against Only one ladder at a time; seeing a player's whole standing takes clicks.

Questions

  1. 1. Layout

    Default: B: a player's whole standing in one look, and SET is next to the rank it changes.

  2. 2. The list's rank column

    With several ladders, the list row has room for one rank.

    Default: The first ladder's rank and points (in A, the chosen ladder's).

  3. 3. SET RANK

    Today it sets the first ladder only. The server can already set any ladder's rung (/rankup player set).

    Default: SET on each ladder opens that ladder's rungs; the rank changes without rewards, as today.

  4. 4. Awards

    There is no give or take for awards yet.

    Default: Show them only: reached, or the points so far out of the points needed. Giving and taking would be a new server rule, so it's a later task.

  5. 5. ADD POINTS

    The admin bonus is one number added to every ladder and award.

    Default: Keep one ADD POINTS and say so beside it: "adds to every ladder and award".

  6. 6. The counts

    Which signals each ladder counts is shown on LADDER and SIGNALS (CS-1).

    Default: In B and C, each count is tagged with the ladders that count it (R, P). In A, the chosen ladder's counts are bright.

  7. 7. RESET

    Default: Unchanged: every count, the bonus and every ladder's rank are forgotten, and the button says "every ladder".

  8. 8. Version

    The player details sent to the admin screen gain a row per ladder and the awards, so the packet changes.

    Default: Protocol 4. If 0.5.0 hasn't gone out yet, it ships in 0.5.0; otherwise 0.6.0. Either way the server and the modpack update together.
